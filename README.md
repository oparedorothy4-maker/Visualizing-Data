# Teen Smartphone Usage Analysis

## Overview
This project analyzes smartphone usage patterns among teenagers to identify behavioral trends and potential indicators of excessive use. The analysis explores how screen time relates to sleep quality, app usage, and academic performance.

## Objectives
- Examine daily smartphone usage among teenagers  
- Identify relationships between screen time and sleep patterns  
- Analyze app usage to determine high-engagement categories  
- Detect patterns linked to academic performance  

## Dataset Description
The dataset contains the following features:

- **Screen Time**: Daily smartphone usage (hours)  
- **App Usage**: Time spent on social media, gaming, and educational apps  
- **Sleep Data**: Sleep duration and quality  
- **Behavioral Indicators**: Focus, mood, and academic performance  

## Key Questions
- How many hours do teenagers spend on smartphones daily?  
- Is there a relationship between screen time and sleep quality?  
- Which apps are most used and potentially addictive?  

## Methodology
- Data cleaning and preprocessing using **Pandas**  
- Exploratory Data Analysis (EDA)  
- Data visualization using **Matplotlib**  
- Correlation analysis to identify relationships between variables  

## Key Findings
- A large proportion of teenagers use smartphones for more than 6 hours per day  
- Higher screen time is associated with reduced sleep quality  
- Social media apps dominate overall usage  
- Increased screen time correlates with lower academic performance
