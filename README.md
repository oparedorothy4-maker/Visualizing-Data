# Teen Smartphone Usage Analysis

## Objective
Analyze smartphone usage patterns among teenagers and identify potential addiction indicators.

## Dataset
Contains data on screen time, app usage, sleep patterns, and behavioral indicators.

## Key Questions
How many hours do teens spend daily on phones?
Is there a link between screen time and sleep?
Which apps are most addictive?

## Key Insights
Teens using phones >6 hours/day show reduced sleep quality
Social media apps dominate usage
Higher screen time correlates with lower academic performance

## Tools Used
Python (Pandas, Matplotlib)
